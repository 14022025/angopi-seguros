# Agencia de Seguros ANGOPI — Rediseño Web Corporativo

Plataforma web B2B de alto impacto para **Agencia de Seguros ANGOPI Ltda.** (Barranquilla, Colombia).

## ✨ Características de Diseño y Arquitectura
- **Dirección Editorial B2B**: Inspirada en firmas líderes globales de corretaje de seguros e intermediación corporativa.
- **Hero Full-Bleed Cinematográfico**: Infraestructura logística e industrial con contraste tipográfico editorial monumental.
- **Identidad de Marca Precisa**: Azul corporativo oficial ANGOPI (`#418ef2`) y modo de contraste dinámico con navegación transparente e inversión suave a barra blanca sticky.
- **Respaldo Institucional (Aseguradoras Aliadas)**: Carrusel infinito continuo con logotipos vectoriales y transparentes oficiales (SURA, MAPFRE, Allianz, Seguros Bolívar, AXA Colpatria, HDI, Seguros del Estado, Chubb, Zurich) sin tarjetas ni marcos circulares.
- **Equipo Humano Real**: Fichas de los 5 integrantes oficiales de ANGOPI con fotografía original, credenciales y contacto directo.
- **Cotizador Express**: Sistema de selección rápida enfocado en conversión directa y cotización técnica vía WhatsApp.
- **Rendimiento y Stack**: HTML5 semántico, Tailwind CSS, FontAwesome 6, JavaScript modular nativo optimizado para móviles y escritorio.
